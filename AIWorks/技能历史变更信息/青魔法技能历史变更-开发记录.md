# 青魔法技能历史变更 · 开发与评审记录

**评审基线**　xiwuaya/blue-mage 的提交 `4a3ca66`。本文对应 `blue-mage-history-import.zip` 中的完整补丁，覆盖技能详情页和第二版在线导入器。首版预览包 `blue-mage-history.zip` 里的使用说明对应旧导入器。

**交付结果**　玩家可以在技能详情页查看国服旧版技能描述、改动前后的差异及出处。本次随包数据覆盖 4.5 至 7.35 的 54 个版本快照。项目的 124 个技能中，有 59 个收录了合计 78 条描述变更。后续更新可能改变这些数字。

## 2. 数据怎样进入页面

1. **确定技能与版本。** 从现有 `tools/data/spells.json` 取得玩家技能的 `action` 和收录的实装版本。按动作 ID 匹配可避开怪物同名技能。在线模式用 `git ls-remote --tags` 取得 `patch-*` 标签，对附注标签取其实际提交。筛选 4.5 起的版本，用 `patch_key()` 排序。
2. **逐版取一张表。** 在线模式按提交 SHA 请求国服解包仓库根目录的 `ActionTransient.csv`，一次在内存中解析一张表。本地模式通过 `git show <sha>:ActionTransient.csv` 读取。两条路径共用 `generate()`。完整 Git 仓库和历版 CSV 都无需保存在使用者磁盘上。
3. **比较两次有效观测。** 过滤未知 ID、空描述和技能实装前的记录。剥离匹配的十六进制 `UIForeground`、`UIGlow` 颜色标签，统一 CRLF，清理首尾空白。首次出现的有效描述作为基线，以后只有正文变化才生成条目。若某技能在中间快照缺行，下次出现时会与上次有效文本比较。
4. **保存可还原的差异。** `changes()` 把连续数字或小数作为一个单元，其他文字逐字符切分，通过 `SequenceMatcher` 对齐。共同片段和替换片段同时保存，页面可准确还原规范化后的原文并高亮改动。
5. **生成静态页。** 导入成功后将 JSON 写入同目录临时文件，再替换目标。日常构建直接读取随项目提交的两份历史 JSON。开发预览和生产详情页共用模板，玩家展开记录时无需请求 GitHub。

数据来源：[拂晓国服解包仓库](https://github.com/thewakingsands/ffxiv-datamining-cn)。

### 水炮样例与字段语义

水炮的动作 ID 为 `11385`。以下是其历史数组中的一条记录：

```json
{
  "from": "5.05",
  "to": "5.1",
  "parts": ["对目标发动水属性魔法攻击　威力：", ["120", "200"]]
}
```

`from` 表示上一次观测到旧描述的快照；`to` 表示本轮首次观测到新描述的快照。顶层 `versions` 将版本号映射到提交 SHA。沿 `parts` 拼接公共字符串和数组下标 0，可还原旧描述；取下标 1 可还原新描述。空串表示这一侧没有相应文字。摘要通过 `summaries["11385"]["5.1"]` 查得「威力 120 → 200」。

## 3. UI 行为与证据边界

「历史变更」位于「效果」与「获取途径」之间。默认折叠，标题显示条数及最近一条摘要。展开后按版本从新到旧排列，每条可再展开「查看改动前后」。旧版与新版全文上下排列，以 `<mark>` 标记差异。模板先用 `esc()` 转义文本，再插入高亮标签。没有历史记录时省略区块；缺少人工摘要时显示「描述文本变更」。

每条记录链接到新旧两个提交中的 CSV 文件。来源链接定位到整张表，复核时应按动作 ID 找行。**当前只有水炮 5.1 在模板中显式关联了官方补丁说明**，显示「技能效果调整」。其余记录显示「最早见于」及「描述文本变更」。若后续增加官方证据，建议将公告 URL 按动作 ID 和版本维护在数据中，避免持续向模板添加条件。[水炮对应的官方 5.1 更新笔记](https://na.finalfantasyxiv.com/lodestone/topics/detail/3a23a8ba13b2c4152681ec4fa5716915b851002f)

## 4. 安装与使用

以下命令在 blue-mage 项目根目录执行。首次安装和升级任选对应路径。

| 你的项目状态 | 操作 |
| --- | --- |
| 尚未安装技能历史功能 | 从第二版包取出 `blue-mage-history.patch`，先运行 `git apply --check blue-mage-history.patch`，通过后运行 `git apply blue-mage-history.patch`。完整补丁已带历史数据 |
| 已应用首版完整补丁 | 从第二版包复制 `tools/update/import-spell-history.py` 到同名位置。也可使用 `git apply --check upgrade-importer.patch` 和 `git apply upgrade-importer.patch` |
| 只想查看交付效果 | 解压首版预览包并打开 `water-cannon.html`。该文件可直接查看水炮的折叠和高亮效果 |

**构建与预览。** 使用项目现有的依赖环境。在项目根目录执行：

```sh
yarn build
yarn preview
```

打开预览地址下的 `/spell/11385/`。开发期间也可运行 `yarn dev` 并访问同一路径。首次安装后直接构建即可。

**维护者刷新数据。** 需要 Git、Python 3.8 或以上版本；在线模式还需要访问 GitHub 和 raw.githubusercontent.com。

```sh
python tools/update/import-spell-history.py
```

如已有带版本标签和历史对象的本地解包仓库，可离线执行：

```sh
python tools/update/import-spell-history.py "/path/to/ffxiv-datamining-cn"
```

两种模式都重建 `tools/data/spell-history.json`。在线刷新会重新获取所有匹配版本，本次 54 张表原始大小合计约 81 MiB。CSV 下载对所捕获的网络错误最多尝试三次；获取标签失败或刷新中断后，可重新执行。一次完整导入成功后，再核对差异、人工更新摘要、重新构建：

```sh
git diff -- tools/data/spell-history.json tools/data/spell-history-summaries.json
yarn build
```
