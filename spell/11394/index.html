精神冲击

No.41 · Lv.16 · 4.5 版本 · 最终幻想14 青魔法师技能

效果

对自身周围的敌人发动无属性范围魔法攻击　威力：200
攻击复数敌人时，对第一个之外的敌人威力降低50%
追加效果：麻痹　持续时间：30秒

获取途径（6 条）

  1. 迷宫 地下灵殿塔姆·塔拉墓园 - 主宰者 加尔梵斯 Lv.16

    BOSS#3。解除限制时也必定学会。低于一定生命值后咏唱，别秒了。

  2. 怪物狩猎 黑衣森林南部林区 [S] - 夺心魔 Lv.50
  3. 大型任务 亚历山大机神城 律动之章2 - 爆破者 Lv.60

    BOSS#1。解除限制时也必定学会，无读条全屏AOE。

  4. 大型任务 亚历山大机神城 律动之章4 - 爆破者 Lv.60

    击败的第三波敌人之一。解除限制时也必定学会，无读条全屏AOE。同一副本还有专属技能 80正义飞踢

  5. 大型任务 亚历山大零式机神城 律动之章2 - 爆破者、爆破者幻象 Lv.60

    BOSS #1，解除限制时也必定学会，低于一定生命值后召唤爆破者幻象。

  6. 大型任务 亚历山大零式机神城 律动之章4 - 爆破者 Lv.60

    击败的第三波敌人之一。解除限制时也必定学会。同一副本还有专属技能 80正义飞踢
