# 多队伍结果新增「应用该配置」按钮

## 需求
「多队伍组合推荐」生成结果后，每行队伍末尾增加「应用该配置」按钮，**处理逻辑与样式完全复用**「最优队伍构成」的现有实现（`applyConfiguration(teamIndices)` + `.apply-text` 样式 + 相同 tooltip）。

## 关键设计点（必须处理）
现有失效策略：输入签名（含三态）变化 → 清空多队伍结果。而「应用该配置」本身就会改三态（隐藏非本队成员）——不处理的话，点击按钮瞬间整个结果消失，按钮不可用。「最优队伍构成」的对应行为是应用后面板继续显示。

**方案**：应用时记录应用后的输入签名快照；签名 watch 触发时若新值等于快照（即本次变化由「应用该配置」引起）则保留结果，否则照常重置。这样：
- 点击某队「应用该配置」→ 页面三态更新（隐藏其余人）+ 结果保留，可继续点其他队伍的按钮切换配置；
- 手动切换可见状态 / 改技能 / 改过滤 / 改人数 → 照常重置，防陈旧结果；
- 应用操作未引起实际变化时不会留下脏标记（比较签名而非布尔标记）。

## 改动（全部在 `src/components/PartyModal.vue`）
1. **脚本**：签名 watch 改造（快照比较）+ 新增 `applyMultiTeamConfiguration(teamIndices)` 包装（调用现有 `applyConfiguration` 后记录快照）。
2. **模板**：多队伍每行 `共可学习 X 个技能` 后追加
   `<span class="apply-text" @click="applyMultiTeamConfiguration(team.userIndices)" title="点击后将隐藏不在该配置中的其他队员">应用该配置</span>`（`team.userIndices` 本就是 originalIndex，与 `applyConfiguration` 入参约定一致）。
3. 样式零新增（复用 `.apply-text`）。

## 验证
1. `vue-tsc --noEmit` + `vite build` 通过。
2. 浏览器实测（dev server 已在运行，HMR 自动生效后重新驱动流程）：种入 4 人数据 → m=2 计算 → 点队伍1「应用该配置」→ 验证页面三态更新（其余人隐藏）且**结果保留**；再点队伍2「应用该配置」→ 配置切换成功；手动点眼睛切换可见状态 → 结果照常重置。
3. 确认「最优队伍构成」原按钮行为不受影响。
