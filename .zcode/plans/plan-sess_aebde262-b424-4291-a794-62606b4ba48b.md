# PartyModal 弹窗滚动条自定义样式

## 现状
`.party-modal`（`overflow-y: auto`，`max-height: 90vh`）使用浏览器默认滚动条。

## 方案（全部在 `PartyModal.vue` 的 `<style scoped>` 内，仅作用于弹窗）

采用「透明轨道 + 细圆柱拇指 + 悬停变粗」的标准 webkit 方案——**滚动条列宽固定，靠 border 缩放实现悬停放大**，不产生布局位移：

```css
.party-modal {
  /* Firefox 降级：细滚动条 + 灰色（Firefox 不支持 ::-webkit-* 与圆角，此为最优近似） */
  scrollbar-width: thin;
  scrollbar-color: #666 transparent;
}
.party-modal::-webkit-scrollbar { width: 12px; }          /* 列宽固定，防跳动 */
.party-modal::-webkit-scrollbar-track { background: transparent; }   /* 透明轨道 */
.party-modal::-webkit-scrollbar-thumb {
  background: #666;
  border-radius: 6px;            /* 圆柱形两端 */
  border: 4px solid transparent; /* 视觉宽 12-2×4 = 4px 细条 */
  background-clip: padding-box;
}
.party-modal::-webkit-scrollbar-thumb:hover {
  border-width: 2px;             /* 悬停时视觉宽变 8px → 放大效果，方便拖动 */
  background-color: #8a8a8a;     /* 略微提亮增强可拖拽暗示 */
}
.party-modal::-webkit-scrollbar-corner { background: transparent; }
```

- 灰色 `#666`、悬停 `#8a8a8a`：与弹窗深色底（#2c2c2c）对比适中；如需更亮/更暗只是改两个色值。
- webkit 伪元素不支持平滑过渡，悬停放大为瞬时切换（Chrome 新版本部分支持 transition，写不写都不影响功能）。
- 只作用于 PartyModal 弹窗，不动页面其他滚动区（左侧过滤面板、textarea 等保持原样）。

## 验证
1. `vite build` 通过（CSS 随构建打包）。
2. dev server 浏览器截图对比：默认态细灰圆柱 + 透明轨道；悬停拇指变粗（用 CUA move 模拟悬停后截图确认）。
