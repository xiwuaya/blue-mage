# `vite.config.ts` 的 `base` 固定为 `/`，站点以根域为前提

`vite.config.ts` 里 `base: "/"` 是**有意为之**，不是漏改。项目正从子路径
（`https://thewakingsands.github.io/blue-mage/`）迁移到根域部署，
`base` 已经于 commit `e73f7f8`（2026-03-27）从 `/blue-mage/` 改成 `/`。
**后续所有改动都应以根域为前提。**

**为什么值得记下来。** 这是一个**代码里完全看不出来的约束**，而且极易被误判为 bug：

- 线上站点当时仍在引用 `/blue-mage/assets/...`，看起来"仓库配错了"；
  实际上那只是**线上还没重新部署**（页面标题都还是旧的「青魔法师技能学习指南」）。
- `public/` 资源在该前提下，绝对路径 `/icons/x.svg` 和相对路径 `icons/x.svg` **都是对的**。
  曾经（包括本项目的一份开发文档里）把它们当成"子路径下会 404 的既有 bug"，是**错误结论**。

搞清楚这一点之前，很容易"顺手修好" `base`，把站点真的弄坏。
